# Rivaa Music Bot

Rivaa is a high-performance Discord music bot designed for fast, reliable, and high-quality music playback across multiple platforms.

It supports modern Discord features, optimized streaming, and a simple command system for users.

---

## Features

• High quality music playback  
• Supports 22+ music platforms  
• Spotify playlist support  
• Fast audio streaming  
• Real-time lyrics system  
• Stable Lavalink based architecture  
• Clean command system  
• Lightweight and efficient

---

## Tech Stack

- Node.js
- TypeScript
- Discord.js
- Lavalink
